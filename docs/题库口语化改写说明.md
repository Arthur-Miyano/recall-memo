# 题库口语化改写说明

所有技术栈的题目采用自然口述风格：直接从问题本身开始回答，随后带出真实开发中的判断和取舍，再补充必要的技术细节。

## 风格规范（2026-09 第二轮改写定稿）

1. 第一句直接回答问题（是什么 / 怎么做 / 为什么），不绕弯子，不用"面试时可以这样回答"等固定话术。
2. 像真人说话：短句、自然的口语连接（"实际上""举个例子""项目里"），想象正在面试官对面回答。
3. 禁用 AI 腔标记词："说白了""一句话总结""一句话区分""简单来说""总的来说""综上所述"一律不用，直接说事。
4. 每题带一点工程判断或取舍（踩坑、排查方法、选型理由），但不编造具体公司名、项目名、数字指标。
5. 长度 2-4 个自然段、约 120-260 字，能两段说清的不写三段，不做总结式收尾。
6. 技术术语保持原文（Agent、token、next-key lock 等），不替换成生硬中文；中英之间正常空格；代码标识符用反引号。
7. 纯文本段落，不用 Markdown 标题和列表语法；枚举融进句子（"常用的有三种：一是…二是…三是…"）。

题干、难度、关键词和标签保持不变；答案改写可重复运行，不会叠加同一段工程语境。

## 数据同步

运行时数据源是 `data/bagu.db`；`data/questions/seed_python.json` 是 Python 种子题（首次运行导入用）。改写答案时两边要同步，可按题干匹配。
