# 单词卡片功能技术路线调研

> 调研日期：2026-09-06
> 需求：背题页面点击答案中的英文单词 → 弹出单词卡片 → 显示中文翻译 + 朗读发音。
> 约束：本地单机单用户（Vue3 + FastAPI）、方案简单、尽量免费、不引入复杂依赖。
> 每条结论均标注一手来源；标注「非官方」表示未找到官方文档。

---

## 一、发音（朗读）方案

### 1.1 浏览器原生 Web Speech API（speechSynthesis）—— 推荐首选

- **功能定位**：`speechSynthesis` 是浏览器内置的文本转语音（TTS）组件，通过设备默认语音合成器朗读文本，**完全免费、无需 API key、无需联网请求任何第三方 API**。
  来源：[MDN - Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API)
- **兼容性**：MDN 兼容性数据标注 SpeechSynthesis 为广泛可用（Widely available），Chrome 33+、Edge 14+ 均支持；本项目目标浏览器为 Chrome/Edge，无障碍。
  来源：[MDN - Web Speech API（Browser compatibility 表）](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API)
- **可用语音取决于本机安装的语音包**：`getVoices()` 返回的是"当前设备上可用的"语音列表。Windows 系统通常预装英文 SAPI5 语音（如 Microsoft David / Zira），Edge（Chromium 内核）还会额外提供在线 Natural 语音（如 `Microsoft Aria Online (Natural) - English (United States)`）。中文 Windows 一般也带英文语音；若没有，可在 Windows 设置 → 语音 中添加英语语音包。
  来源：[MDN - SpeechSynthesis.getVoices()](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices)
- **主要坑（来自 MDN 官方示例与规范）**：
  1. **语音列表异步加载**：首次调用 `getVoices()` 可能返回空数组，必须监听 `speechSynthesis.onvoiceschanged` 事件后再取列表（MDN 官方示例即采用此模式）。
     来源：[MDN - SpeechSynthesis.getVoices() 示例代码](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices)
  2. **中文系统默认语音读英文**：不指定 `utterance.lang = 'en-US'` 或不手动选英文 voice 时，中文 Windows 会用中文语音引擎读英文单词，发音怪异。实现时应从 `getVoices()` 里筛选 `lang.startsWith('en')` 的语音并显式赋给 `utterance.voice`。
  3. 规范层面语音列表也可能由服务端异步确定（规范原文说明）。
     来源：[Web Speech API 规范 - SpeechSynthesis](https://webaudio.github.io/web-speech-api/)
- **评价**：零依赖、零成本、可离线、实现约 20 行 JS，与"简单优先"约束完美契合；音质取决于本机语音包，Edge 在线 Natural 语音音质接近真人。

### 1.2 备选：Free Dictionary API 的发音音频 URL

- **提供发音音频**：响应 JSON 中 `phonetics[].audio` 字段直接给出 mp3 URL（示例：`https://api.dictionaryapi.dev/media/pronunciations/en/at-us.mp3`），前端可直接 `<audio>` 播放。
  来源：[dictionaryapi.dev 官方首页示例](https://dictionaryapi.dev/)、[实测定例 /entries/en/at](https://api.dictionaryapi.dev/api/v2/entries/en/at)
- **免费、无需 API key**：官方首页明示 "Dictionary API is—and always will be—free"，无鉴权要求。
  来源：[dictionaryapi.dev](https://dictionaryapi.dev/)
- **限制**：
  - 仅支持英文单词查询（端点固定 `/api/v2/entries/en/<word>`），且**音频覆盖率不全**——部分词条的 `phonetics[].audio` 为空字符串（实测 `dictionary` 一词多条 phonetics 中 audio 为空）。
    来源：[实测定例 /entries/en/dictionary](https://api.dictionaryapi.dev/api/v2/entries/en/dictionary)
  - 无官方 SLA/限流承诺，属社区免费服务。
- **评价**：真人录音音质好，但覆盖不全 + 依赖外网，适合做"有真人发音则优先用"的增强层，不适合做唯一发音源。

### 1.3 备选：有道发音直链 `dict.youdao.com/dictvoice?audio=<word>`

- **结论：非官方、未文档化接口**。有道官方开放平台（ai.youdao.com）的正式 TTS/词典 API 需要应用 ID + 签名鉴权，文档中不存在该直链；`dictvoice` 是有道词典网页端内部使用的音频 CDN 地址，被社区广泛逆向使用。
- 社区流传的用法：`type=1` 英音、`type=2`（或 `0`）美音，直接返回 mp3。
  来源（均为第三方社区文章，非有道官方）：[CSDN - 揭秘有道隐藏免费发音接口](https://blog.csdn.net/weixin_30266885/article/details/97880750)、[掘金 - 单词接口整理](https://juejin.cn/post/7437366358570008628)
- **风险**：无稳定性承诺，可能随时变更、加 Referer 校验或限频；浏览器直接引用可能受跨域/防盗链影响（更稳妥的做法是由 FastAPI 后端代理转发）。
- **评价**：真人发音、国内 CDN 速度快，体验最好，但"非官方"意味着只能当 fallback 或增强，不能当主链路。

## 二、翻译（英译中）方案

### 2.1 Free Dictionary API —— 确认没有中文翻译

- 官方首页全部示例与端点均为 `/api/v2/entries/en/<word>`，`meanings[].definitions[].definition` 字段为**纯英文释义**，响应结构中不存在任何中文/翻译字段。
  来源：[dictionaryapi.dev 官方首页](https://dictionaryapi.dev/)
- **评价**：做"英英释义 + 发音"可以，做"英译中"不满足需求，翻译场景排除。

### 2.2 MyMemory Translated API

- **免费额度（官方文档原文）**：
  - 匿名免 key：`5000 chars/day`（按字符计，不按请求数）；
  - 请求中带 `de=<你的邮箱>` 参数：`50000 chars/day`。
  来源：[MyMemory - Usage Limits 官方文档](https://mymemory.translated.net/doc/usagelimits.php)
- **用法**：GET `https://api.mymemory.translated.net/get?q=<text>&langpair=en|zh-CN`，无需注册。
  来源：[MyMemory API 文档](https://mymemory.translated.net/doc/usagelimits.php)
- **返回质量**：MyMemory 本质是翻译记忆库（TM）+ 机器翻译聚合，对**单个单词**常返回语料片段匹配而非词典式精准释义，质量不稳定；对短句更好。
- **评价**：免 key 即可用是它的唯一优势；单词级翻译质量和 5000 字符/日的额度都偏弱，适合当联网 fallback。

### 2.3 离线词典库 ECDICT —— 推荐首选

来源：[GitHub - skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)（项目主页 README 为一手来源）、[GitHub REST API 仓库元数据](https://api.github.com/repos/skywind3000/ECDICT)

- **Star 数**：主仓库约 **8.2k stars**（截至 2026-09-06，GitHub API 实测 8223）；终极版仓库 [ECDICT-ultimate](https://github.com/skywind3000/ECDICT-ultimate) 约 273 stars。
- **开源许可证：MIT**（主仓库与 ECDICT-ultimate 均为 MIT，GitHub API `license.spdx_id: MIT`）。**可以自由打包进项目、商用均可，只需保留版权声明**。
- **数据格式**：CSV（UTF-8，字段含 `word / phonetic / definition(英文) / translation(中文) / pos / collins / oxford / tag / bnc / frq / exchange`）；仓库自带 `stardict.py` 脚本可在 **CSV / SQLite / MySQL 三格式互转**，官方推荐本地使用时转成 SQLite（查询快、无等待）。
  来源：[ECDICT README - 数据格式 / 词典使用](https://github.com/skywind3000/ECDICT)
- **现成 SQLite 版本**：README 说明"最新版数据太大，我已经把数据库压缩成 stardict.7z 了"（即作者直接提供打包好的 SQLite 库）；仓库默认 `ecdict.csv` 为基础版（**76 万词条**），[ECDICT-ultimate](https://github.com/skywind3000/ECDICT-ultimate/releases) 提供 **432 万词条**的增强版（`ecdict-ultimate-csv.zip`，93.7MB）。
- **中文释义质量**：双解词典（英文 + 中文释义分行给出），并标注四六级/考研/雅思/托福等考试大纲标签、柯林斯星级、牛津 3000、BNC/当代语料库词频，面试题答案中的技术/常用词汇覆盖率足够。
- **评价**：MIT 许可 + 离线 + 毫秒级本地查询 + 字段丰富，与"本地单机、简单优先"的约束完全吻合；唯一成本是数据文件体积（建议只用 76 万词条基础版，或按需裁剪）。FastAPI 侧加一个 `/api/words/{word}` 查询端点即可，无需引入第三方依赖（Python 内置 sqlite3）。

### 2.4 复用已有 DeepSeek LLM 做单词翻译 —— 工程评估（不查文档）

- 本项目后端已有 LLM 调用链路（`backend/api/llm.py`、`backend/api/assistant.py`），复用 DeepSeek 翻译单词在工程上零新增依赖。
- **延迟**：LLM 单次请求 1~3 秒起步，弹卡片场景下用户感知明显，需 loading 态或流式输出；单词翻译文本极短，**不需要流式**，一次返回即可。
- **成本**：单词翻译 prompt+输出几十 token，单次成本可忽略；但高频点击下依赖外网 API，断网即失效。
- **定位建议**：不做主链路，适合做 **ECDICT 查不到的生僻词/词组时的兜底**，或"AI 详解"增值按钮（结合题目上下文解释该词，这是词典做不到的能力）。

## 三、结论与推荐组合

### 推荐路线（本地单机、简单优先）

| 能力 | 首选 | 理由 |
| --- | --- | --- |
| 翻译 | **ECDICT（SQLite 离线库）** | MIT 许可可直接打包；离线毫秒级；中英双解 + 音标字段一次到位；Python 内置 sqlite3 零新依赖 |
| 发音 | **浏览器 Web Speech API（speechSynthesis）** | 零依赖零成本离线可用；20 行 JS；显式选 `en-US` 语音即可避开中文语音坑 |

### Fallback 顺序

**翻译**（后端 `/api/words/{word}` 内逐级降级）：
1. ECDICT 本地 SQLite（含 `exchange` 词形还原，查不到 `went` 可回退到 `go`）；
2. MyMemory API（联网，免 key，5000 chars/日）；
3. DeepSeek LLM（已有链路，当"AI 解释"兜底）。

**发音**（前端逐级降级）：
1. speechSynthesis + 本机英文语音（离线）；
2. Free Dictionary API 的 `phonetics[].audio` 真人 mp3（联网，覆盖不全）；
3. 有道 dictvoice 直链（联网，**非官方**，仅作最后兜底，建议后端代理）。

### 关键风险

1. **有道 dictvoice 为非官方接口**，随时可能失效或加防盗链——不要让它成为唯一真人发音来源。
2. **speechSynthesis 语音列表异步加载**，首次 `getVoices()` 可能为空，必须监听 `onvoiceschanged`；且需显式指定英文 voice，否则中文系统会用中文引擎读英文。
3. **MyMemory 单词级翻译质量不稳定**且匿名仅 5000 字符/日，只能当兜底。
4. **ECDICT 数据体积**：基础版 76 万词条够用（UTF-8 CSV 数十 MB，转 SQLite 后可放 `data/` 目录）；不建议直接引入 432 万词条的 ultimate 版。
