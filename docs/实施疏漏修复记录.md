# 实施疏漏修复记录

日期：2026-08-23

## 已修复

- 面试回答和跳过改为先完成评分、下一题或复盘准备，再把答题记录、会话推进和操作结果放在同一事务提交。下一题生成失败时仍停在原题，同一幂等键可以继续重试。
- 启动时发现中断在 `INTERVIEW_SCORE` 且尚未推进的操作，会把会话恢复到 `INTERVIEW_ANSWER`，再将操作标记为可重试的 `FAILED/INTERRUPTED`。
- 记忆训练恢复以服务端是否处于 `MEMORIZE_QUIZ/REVIEW_QUIZ` 为准，不再依赖可能滞后的本地 `quizzing`。
- 离线恢复真实会话后，开始考核、回答、跳过和保存笔记均禁止写入；mock 演示仍只走本地。
- CI 的 push 分支改为仓库实际使用的 `master`。
- LLM 只分类已知 HTTP、超时和网络异常，未知程序异常原样抛出。
- LLM 设置先写入 `.env`，成功后才更新当前进程配置并重载路由。
